# Cozy Social — บ้านเล็ก ๆ ของพวกเรา

เกมเว็บต้นแบบสำหรับนัดเพื่อนมาคุยและเล่นมินิเกม รองรับห้องละ 10 คน มีเซิร์ฟเวอร์ WebSocket จริง ใช้ตัวละครภาพวาด 2D Japanese Chibi โทนอุ่นตามภาพอ้างอิง

## เริ่มเล่น

ต้องมี Node.js 22.12 ขึ้นไป (ทดสอบด้วย Node 24) และ npm

```powershell
npm install
npm run dev
```

เปิด http://127.0.0.1:5188 เลือกลุคและตั้งชื่อ จากนั้นสร้างห้องใหม่หรือกรอกรหัสห้อง 6 ตัว เพื่อนที่เข้าใหม่ระหว่างมินิเกมจะดูรอบปัจจุบันและเข้าร่วมเล่นรอบถัดไป

- เดินด้วย WASD / ลูกศร หรือคลิก/แตะพื้น
- กด E หรือปุ่ม “ลงมือทำ” เมื่อเข้าใกล้จุดงานที่มีแสง
- ส่งข้อความผ่านแชต และอีโมตที่แสดงเหนือหัว
- เจ้าของห้องเลือกเกมและเริ่มรอบ เมื่อเจ้าของออก สิทธิ์จะย้ายให้ผู้เล่นคนถัดไป
- ช่วยกันทั้งห้อง 1–10 คน หรือแบ่งทีมละ 2 คนตามลำดับเข้าห้อง (จำนวนผู้เล่นต้องเป็นเลขคู่)

## ชวนเพื่อน

กด “ชวนเพื่อน” เพื่อดูรหัสและคัดลอกลิงก์ เมื่อเปิดจาก localhost ปุ่มจะแสดง IP เครือข่ายของเซิร์ฟเวอร์ให้เลือก เพื่อนต้องใช้ Wi-Fi/LAN เดียวกันและเครื่องเซิร์ฟเวอร์ต้องอนุญาต TCP 5188 ผ่านไฟร์วอลล์ หากเครื่องมีหลายอะแดปเตอร์ ให้เลือก IP ของ Wi-Fi/LAN ที่เพื่อนใช้อยู่ ไม่ใช่อะแดปเตอร์ VPN

ลิงก์ localhost/127.0.0.1 เปิดได้เฉพาะเครื่องนั้น การเล่นผ่านอินเทอร์เน็ตต้อง deploy เซิร์ฟเวอร์ Node ที่เพื่อนเข้าถึงได้ ใช้ HTTPS และ reverse proxy ที่รองรับ WebSocket upgrade เส้นทาง /ws (ไคลเอนต์เลือก wss อัตโนมัติเมื่อเปิดผ่าน HTTPS)

## มินิเกม

- **ครัวอุ่นใจ**: หยิบวัตถุดิบ → ปรุงอาหาร → รอ 3 วินาที → เสิร์ฟ รับ 100 แต้มต่อชุด
- **บ้านน่าอยู่**: หยิบอุปกรณ์ → ประกอบของแต่ง → รอ 3 วินาที → จัดเข้ามุม รับ 100 แต้มต่อชุด

แต่ละรอบ 2 นาที สมาชิกในทีมทำขั้นตอนต่อจากเพื่อนได้ คะแนนและความคืบหน้าตรวจที่เซิร์ฟเวอร์ ทีมละ 2 คนใช้สถานีเดียวกันแต่แยกความคืบหน้าและคะแนน ตอนนี้เป็น gameplay loop ขั้นต้น ยังไม่มีระบบถือ/โยนวัตถุ ออเดอร์หลายสูตร แผนที่หลายด่านแบบเกมเต็ม

## ตัวละครและขอบเขต

- หน้าหลักเป็นหน้าตู้เสื้อผ้าใหม่ ใช้ภาพวาด chibi พื้นหลังโปร่งใส พร้อมห้องแต่งตัวอบอุ่น
- มี **4 ลุคสำเร็จทั้งชุด** ทรงผม เสื้อผ้า และเครื่องประดับเปลี่ยนพร้อมกัน ยังแยกเปลี่ยนชิ้นส่วนของภาพวาดไม่ได้
- บันทึกชื่อและลุคใน LocalStorage ใช้ลุคเดียวกันในห้องออนไลน์ และเปลี่ยนลุคขณะอยู่ในห้องได้
- หน้าต้นแบบ procedural แบบเก่าเก็บไว้ที่ /creator.html เป็นงานอ้างอิงแยก ไม่ได้เชื่อมรูปลักษณ์เข้ากับห้องใหม่
- ห้อง แชต และคะแนนอยู่ในหน่วยความจำ ไม่เก็บถาวร ห้องหายเมื่อทุกคนออกหรือเซิร์ฟเวอร์รีสตาร์ต
- หลุดการเชื่อมต่อแล้วเข้าห้องใหม่ด้วยรหัสได้ หากยังมีเพื่อนอยู่ ไม่มีระบบคืนตัวตน/ทีมเดิมอัตโนมัติ
- มีแชตข้อความ ยังไม่มี voice chat บัญชีผู้ใช้ หรือระบบ moderation สำหรับเปิดให้คนทั่วไป
- ตัวละครแต่ละลุคมี sprite sheet 24 เฟรม: เดิน 4 ทิศ × 4 เฟรม, สีหน้า 4 แบบ, ท่ากิจกรรม 4 แบบ มุมเฉียงใช้ทิศใกล้เคียง ไม่ใช่ 8 ทิศแยกภาพ
- กด “ดูมุมมองและท่าตัวละคร” ในหน้าแต่งตัว หรือ “ท่าตัวละคร” ในห้อง เพื่อดูตัวอย่างทุกเฟรม
- ภาพ sprite เป็นงานสร้างด้วย AI และจัด atlas ด้วย metadata ยังมีความต่างเล็กน้อยระหว่างเฟรม ไม่ใช่ skeletal rig หรือระบบเปลี่ยนชุดแยกชั้น

## Build และใช้งานจริง

```powershell
npm run build
npm start
```

เซิร์ฟเวอร์ให้บริการ dist และ WebSocket บนพอร์ตเดียวกัน เปลี่ยนพอร์ตด้วยตัวแปร PORT เช่น `$env:PORT=8080` ไม่ควร deploy เฉพาะไฟล์ static หากต้องการ multiplayer

## ตรวจสอบ

```powershell
npm test
# เปิด npm run dev ไว้ก่อน ต้องมี Google Chrome
node tests/browser-smoke.mjs
node tests/network-smoke.mjs
node tests/isometric-smoke.mjs
```

- Unit tests: ความจุห้อง สิทธิ์โฮสต์ แยกห้อง จับคู่ ขอบเขต/ความเร็วการเดิน ระยะทำงาน เวลาปรุง คะแนน หมดเวลา ผู้ชม การย้ายโฮสต์ และ rate limit
- Browser smoke: desktop/mobile, เปลี่ยนลุค, ผู้เล่นสองคน, แชต, มินิเกมและคะแนนร่วมกัน, เปลี่ยนลุคในห้อง และออกจากห้อง ภาพตรวจงานอยู่ output/qa
- Network smoke: เชื่อม WebSocket จริง 11 clients เพื่อยืนยันรับ 10 คนและปฏิเสธคนที่ 11

ภาพสร้างด้วย built-in imagegen ดู prompt และตำแหน่งไฟล์ใน docs/art-prompts.md


## ห้อง Isometric และ Modular Building

- เปลี่ยนห้องเล่นเป็นภาพ 2D isometric อัตราส่วนกระเบื้อง 2:1 พื้นที่ 18 × 14 ช่อง แยกพิกัดโลกออกจากกล้อง
- พื้นแต่ละช่องและผนังด้านหลังวาดแยกชิ้น มีเฟอร์นิเจอร์ 18 ชิ้นจาก atlas โปร่งใส 2 ชุด และพรมอีก 1 แบบ รวม 19 แบบ
- เลือกของจากหมวดนั่งเล่น, ทำงาน/เก็บของ, ครัว หรือพักผ่อน/ตกแต่ง มีเตียง โต๊ะน้ำชา บีนแบ็ก โคมไฟ ตู้เย็น อ่างล้างจาน เตาอบ ตู้เก็บของ และคอนโดแมวเพิ่มเข้ามา
- เจ้าของห้องกด **จัดห้อง** เลือกชิ้นส่วน แล้วคลิกหรือแตะช่องว่างเพื่อวาง กด **หมุน / R** เพื่อสลับแนว 0° / 90° (ภาพสลับด้านและขนาดพื้นที่ ไม่ใช่โมเดล 3D หมุนอิสระ)
- **ย้าย**: แตะช่องที่มีของ แล้วแตะช่องใหม่; **ลบ**: แตะช่องที่มีของ; **ปูพื้น**: เลือกสีและแตะช่อง
- กริดแสดงรอยวางสีเขียว/แดง เซิร์ฟเวอร์ตรวจขอบห้อง พื้นที่ทับกัน ตำแหน่งผู้เล่น และทางเดินที่ถูกปิดกั้น ใช้ revision ป้องกันคำสั่งเก่าทับสถานะใหม่
- วางได้สูงสุด 100 ชิ้นต่อห้อง ทุกคนเห็นการจัดวางตรงกัน โหมดจัดห้องใช้ได้ตอนพักระหว่างเกมเท่านั้น
- แถว 8–10 (index เริ่มที่ 0) สงวนเป็นจุดมินิเกมและทางสัญจร เปลี่ยนสีพื้นได้แต่วางเฟอร์นิเจอร์ไม่ได้
- คลิกพื้นเพื่อเดินตามเส้นทางที่หลบเฟอร์นิเจอร์ หรือใช้ WASD/ลูกศร เดินชนของไม่ได้
- ซูมด้วย + / − หรือ scroll wheel, เลื่อนกล้องด้วย Shift + ลาก / ปุ่มเมาส์กลาง และกดเปอร์เซ็นต์เพื่อคืนมุมกล้อง
- การจัดห้องเก็บในหน่วยความจำของห้องเช่นเดียวกับแชต ยังไม่บันทึกถาวรข้ามการปิดเซิร์ฟเวอร์
