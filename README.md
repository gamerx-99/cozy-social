# Cozy Social — Character Creator Prototype

เว็บต้นแบบหน้าสร้างตัวละครสำหรับเกม Cozy ที่ผู้เล่นเข้ามาพบปะเพื่อนและพักผ่อน ตัวต้นแบบนี้เน้นการปรับรูปลักษณ์และเห็นผลกับตัวละครทันที ยังไม่ใช่เกมออนไลน์หรือหน้าเข้าเล่นกับเพื่อน

## สิ่งที่ทำได้ในต้นแบบนี้

- เลือกรูปแบบตัวละครชาย/หญิง โดยตัวเลือกเสื้อผ้าและเครื่องประดับใช้ร่วมกันได้
- ปรับทรงผมและสีผม, รูปตาและสีตา, สีผิว, เสื้อ, กางเกง, รองเท้า และอุปกรณ์เสริม
- ดูตัวอย่างตัวละครแบบ realtime และขยับด้วย WASD/ปุ่มลูกศร
- สุ่มลุคหรือกลับไปค่าตั้งต้น
- ยืนยันและบันทึกรูปลักษณ์ใน LocalStorage ของเบราว์เซอร์เครื่องนั้น
- ข้อมูลรูปลักษณ์แยกจากสถานะการเล่นเกม

## ขอบเขตที่ยังไม่ทำ

ยังไม่มีห้อง multiplayer, lobby, แชต, พื้นที่พบปะที่เล่นได้, บัญชีผู้ใช้, การ sync ข้ามเครื่อง หรือมินิเกม ภาพฉากและหน้าปรับแต่งที่สร้างไว้เป็นภาพอ้างอิงแนวทาง ไม่ใช่ชิ้นส่วน sprite หรือ UI ที่นำมาแสดงในตัวต้นแบบนี้

## รันในเครื่อง

ต้องมี Node.js 20 ขึ้นไปและ npm

```bash
cd /home/gserver/.openclaw/teams/shop/output/2026-10-18-office-rush-game/character-prototype
npm install
npm run dev
```

จากนั้นเปิด URL ที่ Vite แสดง (ปกติ `http://localhost:5173`).

## Build

```bash
npm run build
```

ไฟล์ static จะสร้างใน `dist/` เพื่อใช้ต่อกับขั้น hosting ภายหลัง
